| **Defense Reward Score** | -44.902 | **494.098** | -539.00 |

### Insights:
The ablation study highlights a key learning pathology: when memory is enabled, the agent queries the memory database using cosine similarity. If it matches a historical state, it executes the recalled action. Because early co-evolution states contained sub-optimal containment decisions (high false isolation calls), the memory database "pollutes" the agent's actions with high-penalty proactive isolates. In contrast, disabling the memory forces the agent to rely solely on its base PPO policy, which has learned to be less aggressive, increasing its average reward to $494.098$. This emphasizes the critical need for memory cleaning and database optimization in future work.

### Conclusion:
The t-tests reject the null hypotheses with high confidence. The PPO agent's performance is statistically distinct from both random exploration and static rule-based policies, verifying that the learned policy represents a structured, active strategy.
