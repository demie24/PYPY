# Core AI Detection Service

The AI Anomaly Detection service analyzes real-time grid telemetry from the Digital Twin and the physical ESP32 terminal to identify cyber-physical security anomalies, including False Data Injection Attacks (FDIA) and unauthorized remote trips.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run detector service:
   ```bash
   python src/detector.py
   ```
