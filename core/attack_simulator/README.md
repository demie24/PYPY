# Core Attack Simulator

The Attack Simulator tests the resilience of the grid system and evaluates the performance of the AI Detection Agents by orchestrating and executing various cyber-physical attack scripts.

## Attack Profiles
1. **FDIA (False Data Injection Attack)**: Injects biases or scale factors on voltage or current telemetry.
2. **Breaker Spoofing**: Commands breakers to open, triggering cascading blackouts.
3. **Replay Attack**: Records telemetry stream and replays it to mask physical failures or active attacks.
4. **DoS (Denial of Service)**: Mimics message drops or communication delays.
