# Core Digital Twin Simulator

The Digital Twin Simulator models the physical characteristics of the power grid, solving the power flow equations, updating line/bus parameters, and simulating the state of physical lines and breaker systems.

## Prerequisites
- Python 3.9+
- Packages: `pandapower`, `websockets`, `numpy`

## Getting Started
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Start simulator:
   ```bash
   python src/simulator.py
   ```
