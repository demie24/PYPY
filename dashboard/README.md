# Smart Grid Security Dashboard

The dashboard is a dynamic frontend visualization platform built with React, Vite, and Tailwind CSS.

## Features
- **Single Line Diagram (SLD)**: SVG-based reactive visual representation of buses, generators, loads, transmission lines, and circuit breakers.
- **Security Alert Console**: Shows live intrusion alerts generated by the AI detection agents.
- **Cyber-Physical Attack Controls**: Interactive controls allowing users to inject FDIA, DoS, and tripping attacks.
- **Self-Healing Override**: Manual/Auto toggles for FLISR logic execution.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start local server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:5173](http://localhost:5173) in your browser.
